SanZa Games is a family-friendly corner of the SanZa world: original browser games, Yup Bro, and Funny Zone. Lead with the fun and show real gameplay. Do not promise features that are not currently live.

## Google Search / SEO checklist
- Keep one clear topic per page and write a unique, accurate title and meta description.
- Give every game a useful description explaining how to play, controls, audience and what makes it different.
- Use descriptive internal links between the homepage, individual games and Funny Zone.
- Keep the sitemap and robots.txt accurate; include only canonical, indexable URLs that return successfully.
- Keep canonical URLs, mobile usability, HTTPS and page performance healthy.
- Do not create thin doorway pages, keyword-stuff text, buy backlinks or promise rankings.
- Check Google Search Console for indexing and page experience; request indexing only after a page is genuinely ready.
- Preserve existing privacy, consent and AdSense code. Never add ad clicks or ask visitors to click ads.

## QR sharing
Use `assets/sanza-games-qr.svg` on flyers, posters or a phone screen. It points to https://sanzagames.ie/. Test-scan the printed copy before distributing; leave a clear white quiet-zone around the code and do not place a logo over it.

## Weekly rhythm (repeat for four weeks)
- Monday: Yup Bro short video.
- Tuesday: one game clip / challenge.
- Wednesday: one useful community interaction; post only where allowed.
- Thursday: Funny Zone feature.
- Friday: repost the best-performing original clip to YouTube Shorts.
- Saturday: ask followers to challenge a friend.
- Sunday: review Analytics and record which post brought visits.

## Measurement
Record weekly: active users, new users, sessions, engagement rate, top landing pages, and traffic source / medium. Use consistent campaign tags for links shared in posts, e.g.:
`https://sanzagames.ie/?utm_source=youtube&utm_medium=organic_social&utm_campaign=yupbro_launch`
Use a different source for TikTok, Instagram, Facebook and Reddit so visits can be compared. Do not put personal data in tracking URLs.

## Safety and release rules
- This campaign folder is a separate preview branch; it does not deploy to production by itself.
- Do not merge to `main`, change GitHub Pages settings, change the custom domain, or alter Vercel production.
- No paid boosts, subscriptions, ad spend or paid API.
- No spam, fake reviews, misleading claims, or targeting children with requests for personal information.
- Before publishing any website change, inspect it on a preview and get explicit approval.
